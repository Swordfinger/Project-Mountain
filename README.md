这或许是一个被天使遗忘的大世界 人们被困在天使创造的层层牢狱世界中 每向上一层的世界就会更加的危险 世界的景象也会更加的恐怖 这一切发生是为了惩罚那些曾经犯错以及背叛天使的使者，在这个大世界中有四层牢狱世界 每一个牢狱世界都被封印着一个使者 这些使者每天都在承受着天使的惩罚 他们流下的罪恶的血液却在数百年间形成了新的生命 这些留着罪恶的使者血脉的人们是无辜的 但是对于他们的存在却被掌管这个牢狱世界的狱卒使隐瞒了下去 狱卒使每隔数十年就会对一层小世界造成震荡取乐 每一次震荡都会危及这一小世界所有人的生命。

一位衣衫褴褛的老者对路上的一些孩子讲述着这个故事 大人们并不相信他的胡言乱语 所以只有孩子们愿意听他的故事 孩子们很好奇他为什么知道这些故事 老者用沧桑的语气说：因为我曾经与那狱卒使战斗过只不过他的强大远远超过了我的想象。 原来这位老者在年轻的是时候非常不理解为什么人们一出生就要在这样悲惨的世界生存 为了寻找答案他不断的向上攀爬不断挑战沿途的敌人 后来他发现天使并不知晓这个世界发生的所有事情  因为这里发生的一切由于狱卒使的私心而无法传导到天使的耳中 所以他想通过自己的努力让天使知道在层层世界中有着许多无辜的生命以及揭露狱卒使的罪责 而向上攀爬的手段有很多或是贿赂掌管上升渠道的守梯人或是击败一个个看门者。

一些孩子听了老者的故事也对这个世界产生了好奇 有的甚至继承了老者的意志 虽然他们为了生存融入了各种职业 但是他们的目标是一致的 打败狱卒使让天使拯救无辜的人们 这些人被狱卒使成为告密者 终于有一些人在路上相遇他们相约结伴而行共同挑战一个个的敌人 但是人心依旧是难测的 但是人们为了或者总做出一些出人意料地选择 但是他们最终目的都是为了活下去拯救让天使重新降临这个世界拯救痛苦的人
